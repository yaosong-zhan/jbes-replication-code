# Data availability

The replication code is available at <https://github.com/yaosong-zhan/jbes-replication-code>. The Monte Carlo experiments can be rerun from the supplied scripts and result files. The empirical application uses proprietary tick-level limit-order-book snapshots from the Shanghai and Shenzhen Stock Exchanges, earnings-report dates from the RESSET database, and a trading calendar. These data are available under license from their providers and cannot be redistributed. Researchers with the required licenses can set JBES_DATA_ROOT to a local directory outside the repository and run the empirical pipeline described in README.md. The licensed files must not be committed or redistributed.
